# Vue 3 + Vite

This template should help get you started developing with Vue 3 in Vite. The template uses Vue 3 `<script setup>` SFCs, check out the [script setup docs](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup) to learn more.

Learn more about IDE Support for Vue in the [Vue Docs Scaling up Guide](https://vuejs.org/guide/scaling-up/tooling.html#ide-support).

### Общие элементы сайта

В админке категория «Общие элементы сайта» объединяет «Сайдбар», «Хедер и меню»
и «Футер». Все разделы редактируются на русском и английском. Хедер поддерживает
добавление, удаление и перестановку ссылок; одно меню используется на всех экранах.
В сайдбаре доступны контакты, текст об офисе, подпись кнопки карты, отдельные
названия направлений и дополнительные ссылки. Названия направлений по умолчанию
наследуются из категорий портфолио, новые категории подключаются автоматически.

В копирайте футера используется `{year}`, например `© {year} MAGNAT PROFESSIONAL`.
Год подставляется автоматически при отображении сайта. Можно настроить ссылки
футера и двуязычную подпись справа с необязательной ссылкой.

Данные сохраняются в `public.site_chrome_content`. При запуске обновлённого
бэкенда таблица создаётся автоматически через существующее подключение Postgres
(`POSTGRES_PASSWORD`). Если автоматическая миграция отключена, выполните
`backend/src/content/siteChrome.sql` в базе вручную. Обновите фронтенд и бэкенд.
При отсутствии сохранённых настроек используются прежние тексты сайта.
